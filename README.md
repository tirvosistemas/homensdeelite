# Homens de Elite — Jornada da Forja

Sala de aula interativa em desenvolvimento, baseada no briefing e no conteúdo oficial do curso.

## Primeira fase

- HTML5, CSS3 e JavaScript moderno.
- Interface responsiva em português, inspirada na identidade preta, creme e vermelha da marca, com destaques laranja fluorescente.
- Seis módulos, aulas, exercícios, avaliações e ferramentas educacionais.
- Progresso, XP, patentes, conquistas e anotações com armazenamento local temporário.
- Sem autenticação real, banco de dados, pagamentos ou backend nesta fase.

## Continuidade do trabalho

Cada etapa de implementação deve ser salva e enviada a este repositório. Confirmar o commit remoto antes de avançar. Nunca armazenar senhas ou chaves secretas no código.
