Quero que você se prepare para criar uma plataforma educacional interativa chamada:

# HOMENS DE ELITE

O projeto será um treinamento digital voltado para formação masculina, caráter, disciplina, autodomínio, desenvolvimento pessoal, responsabilidade, trabalho, saúde, relacionamentos, liderança, família e construção de uma vida de valor.

# 1. VISÃO GERAL DO PROJETO

Quero criar muito mais do que uma página contendo textos.

Quero uma verdadeira:

**SALA DE AULA DIGITAL INTERATIVA**

O aluno entra na plataforma e sente que está dentro de uma área de membros profissional.

- artigo;
- PDF;
- blog;
- página gigantesca de texto.

Quero uma experiência semelhante a uma plataforma moderna de treinamento.

O aluno deverá poder:

- navegar entre aulas;
- acompanhar seu progresso;
- concluir aulas;

# 11. CONTEÚDOS EXPANSÍVEIS

Uma das ferramentas mais importantes será o sistema de blocos que podem ser abertos e fechados.

Por exemplo:

### ▸ Manda repetidas mensagens para quem não demonstra reciprocidade

O aluno clica.

Abre uma explicação completa mostrando:

- o que esse comportamento significa;
- por que acontece;
- o que existe psicologicamente por trás;
- como reconhecer isso em si mesmo;
- exemplo;
- consequências;
- comportamento alternativo.

Depois ele pode fechar novamente.

Quero utilizar bastante esse recurso.

Ele será especialmente útil em listas longas.

# 12. EXEMPLO: SINAIS DO MODO GADO

Quando houver uma aula mostrando sinais comportamentais, não quero simplesmente quinze frases.

▸ Insiste quando não existe reciprocidade.

▸ Gasta dinheiro para tentar impressionar.

▸ Idealiza uma pessoa que mal conhece.

▸ Aceita desrespeito por medo de perder.
