# AULA 2 — A GUERRA CONTRA O “DEPOIS”

Uma das palavras mais perigosas para um homem sem sistema é:

**depois.**

Depois eu treino.

Depois organizo.

Depois estudo.

Depois começo.

Depois resolvo.

O problema é que “depois” não possui horário.

Transforme:

“depois”

em:

> **“às 19h30.”**

A tarefa que não possui lugar no tempo costuma perder para a distração que aparece primeiro.
